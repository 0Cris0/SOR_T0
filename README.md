## Información General
### Compilado y ejecución
Para poder compilar la tarea se debe abrir una terminal en el mismo directorio que se encuentra el Makefile y ejecutar el comando *`make`*

Una vez completado ese paso, se ha de ejecutar la tarea con *`./dccAdmin [{time_max}]`*, donde uno podrá interactuar con la shell según lo pedido en el enunciado.

* Aquí *`time_max`* es opcional, indicando la cantidad máxima de segundos que un proceso puede demorarse antes de ser terminado. En su ausencia, los procesos tienen tiempo ilimitaod para ejecutarse
